# 🚀 Chat-APP - Real-Time MERN Chat App

**Cheat** is a high-performance, real-time messaging platform built for speed and seamless communication. It allows users to connect instantly, share media, and track message status in real-time.

**🔗 Live Demo:** [https://chat-app-fahimx51.web.app](https://chat-app-fahimx51.web.app)

---

## ✨ Features

* **Real-Time Messaging:** Instant text delivery powered by **Socket.io**.
* **Media Sharing:** Send images seamlessly with **Cloudinary** integration.
* **Seen/Unseen Status:** Live visual indicators for read receipts.
* **Online Presence:** Real-time tracking of active users.
* **Secure Auth:** Protected routes using **JWT** and password hashing with **BcryptJS**.
* **Responsive UI:** A modern, "mobile-first" design built with **Tailwind CSS**.

---

## 🛠️ Tech Stack

### Frontend
* **React.js** – UI Framework
* **Tailwind CSS** – Utility-first CSS for modern styling
* **Axios** – Promise-based HTTP client for API calls
* **Lucide React** – Clean and consistent iconography

### Backend
* **Node.js & Express** – Server-side environment and routing
* **MongoDB & Mongoose** – NoSQL database and object modeling
* **Socket.io** – Real-time, bi-directional event-based communication
* **JSON Web Token (JWT)** – Secure user authentication
* **Cloudinary** – Cloud-based image and video management
